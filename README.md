# NoMaster 🚀

A fun **.NET MAUI** cross-platform app that calls the public **No-as-a-Service (NaaS)** API to deliver random, creative, and polite rejection messages.

Perfect demo app to showcase:
- Modern .NET MAUI UI (dark theme, shadows, rounded borders)
- Consuming REST APIs with `HttpClient`
- JSON deserialization
- Handling HTTP caching for dynamic content
- Cross-platform deployment (Android, iOS, Windows, macOS)

## 🎯 Features

- Tap **"Get a No!"** → get a fresh, hilarious rejection every time
- Loading spinner while fetching
- Beautiful dark mode UI with shadows and rounded elements
- Built with pure .NET MAUI – single codebase, multiple platforms
- Less than 100 lines of meaningful code

## 🛠️ Tech Stack

- **.NET MAUI** (.NET 8 or .NET 10 recommended)
- C# with async/await
- XAML for declarative UI
- Standard `HttpClient` + `System.Net.Http.Json`
